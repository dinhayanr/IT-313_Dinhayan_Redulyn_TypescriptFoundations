# IT313 TypeScript Foundations

## Problem

This project is an Enrollment Eligibility Checker rewritten from JavaScript into TypeScript.

## TypeScript Concepts Used

- Basic type annotations
- Interfaces
- Enum
- Optional properties
- Union types
- Generics
- Async/Await
- Try/Catch
- Type narrowing
- ES module import/export
- Map and Reduce

## How to Run

Install dependencies:

npm install

Compile TypeScript:

npx tsc

Run the program:

node main.js

Check for type errors:

npx tsc --noEmit
